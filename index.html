Connect to GitHub

The bot’s settings live in the private repository BurkhonNurmurodov/safia-tracker-bot. This page edits them with a GitHub access token, which you set up once on each device.

  1. Create a token

    On the GitHub page, under Repository access, choose Only select repositories and pick safia-tracker-bot. Contents is already set to Read and write. Press Generate token and copy it.

    Open GitHub’s token page (opens in a new tab)

  2. Paste it here

The token stays in this browser and is sent only to GitHub. If it expires, this page asks for a new one.
