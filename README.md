# Reminder bot settings

The settings page for the team's Notion deadline reminders in Telegram:
**https://burkhonnurmurodov.github.io/safia-tracker-settings/**

It's a static page. It holds no data and no secrets: after you connect it with a GitHub token, it
reads and writes `data/settings.json` in the private bot repository through GitHub's API, straight
from your browser. Only people who can edit that repository can change anything.
